# Sorter
Tiny Java utility that demonstrates two classic algorithms for ordering an int[]:

Bubble(int[] list) – in-place bubble sort implementation

insertionSort(int[] array) – in-place insertion sort

sort(int[] array) – convenience wrapper (currently calls insertion sort) 

bash
Copy code
# compile & run
javac Sorter.java
java Sorter          # edit main() to pass a test array
